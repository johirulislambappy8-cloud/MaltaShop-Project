# MaltaShop Microservices Project

This project demonstrates a basic microservices architecture for MaltaShop using Python and FastAPI.

## Services

- Order Service: http://localhost:8000
- Notification Service: http://localhost:8001

## Health Check

- Order Service: http://localhost:8000/health
- Notification Service: http://localhost:8001/health

## Current Progress

- Created Order Service
- Created Notification Service
- Tested health endpoints
- Initialized Git repository

## Planned Features

- Separate databases for each service
- Asynchronous messaging using RabbitMQ
- Docker Compose setup
- Automated tests and GitHub Actions CI
